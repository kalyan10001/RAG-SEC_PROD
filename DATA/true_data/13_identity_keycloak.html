Compute Match — Identity and Keycloak

Realm and clients

  • Single realm: customer (organizations enabled). Older provider/operations realm files exist but the application uses one unified realm.
  • Local realm export: keycloak/realms/local-realm-customer.json.
  • Main clients: customer-web (frontend OIDC), workflow-worker (Temporal service account), audit-listener, superset, swagger, temporal-ui.
  • Identity broker Starfleet (NVIDIA SSO) with a starfleet-roles mapper. The frontend sends kc_idp_hint=starfleet.

Roles

customer, provider, provider_business_user, provider_basic_user, platform_business_admin, platform_business_admin_super_user, platform_business_admin_ops_user, account_manager_consumer, account_manager_provider, superset_users, superset_admins, superset_dashboard_viewers, plus the composite default-roles-customer.

Groups used by the app: offering-validator (magic-link recipients), mailing-list.

Custom extensions (keycloak-extensions/)

Extension What it does
accept-reservation-token Custom action token for magic links: validates the JWT, blocks a different logged-in user, validates the nonce with the backend, creates the session and redirects. Exposes the token-minting REST endpoint with a rate limiter
audit-event-listener Sends LOGIN and LOGOUT events (and errors) to the backend /api/v1/internal/audit/keycloak-event
default-role-restriction Self-signup users keep default-roles-customer; admin-created users have defaults stripped
multi-org-policy Only account-manager roles may belong to more than one organization

Build with keycloak-extensions/build.sh; images from keycloak/Dockerfile and keycloak/Dockerfile-local.

Themes

The NVIDIA theme lives in keycloak/themes/nvidia/ (login, account, admin, email). The login theme extends keycloak.v2 and adds organization-type registration fields (enterprise, government, sme_msme, startup).

Organizations

  • Keycloak Organizations model NCP and customer companies.
  • NCP organization names come from the Salesforce account name; one organization per Salesforce account.
  • The organization JWT claim carries the user’s organization; the backend stores matching organization records.

Local Keycloak

  • Admin console: http://localhost:8080/admin, realm customer.
  • Management/health port: host 9001.
  • Admin credentials are generated into local-setup/.onboarding/credentials.json.
