Compute Match — Backend API Reference (Summary)

Interactive documentation runs at http://localhost:8082/docs locally. A snapshot is in backend/openapi.json (it omits Access Request and internal routes). Routers are in backend/infrastructure/driving/http/routers/ and are mounted in main.py. All business APIs are under /api/v1 (one v2 endpoint).

Inventory APIs (reference data)

Countries, geographical regions, GPU models, hosting providers, interconnect types, regions — read with view_capacity; create geographical region or GPU model with manage_inventory.

Users APIs

Method Path Purpose
POST /api/v1/user Provision the signed-in user from JWT claims (organization, partner domain checks; may create an access request)
GET /api/v1/user Current user
POST /api/v1/users/me/terms-acceptance Record Terms and Conditions acceptance
POST /api/v1/auth/logout Logout

Operations APIs (role operations)

Activate user, list users, resend activation magic link, delete user.

Feedback APIs

Submit feedback, check eligibility (/api/v1/feedback/eligibility), record prompt state (/api/v1/feedback/prompt). Feedback kinds: POST_TASK, GENERAL, CANCELLATION, DROP_OFF. Journeys: capacity_upload, reservation_request, app_general. Categories: suggest_feature, report_problem, general. Prompt states: SHOWN, SUBMITTED, SKIPPED, DISMISSED.

Internal APIs (hidden from schema)

  • POST /api/v1/internal/salesforce/offtake-sync, /notify-failure, /partner-domain-sync — caller client_id must equal SFDC_SYNC_CALLER_CLIENT_ID.
  • POST /api/v1/internal/audit/keycloak-event — Keycloak audit listener ingest.

Cross-cutting behaviour

  • JWT validation against Keycloak; permissions from scope, realm_access.roles and resource_access.*.roles claims.
  • Middleware blocks users who are PENDING or have not accepted terms (with an allowlist for the endpoints needed to finish setup).
  • Request body limit 15 MB; CSV upload limit 10 MB.
  • Redis-backed rate limiting per bucket.
