Compute Match — Analytics with Superset

Apache Superset (superset/) provides dashboards for Platform Admins. Locally, start it with make onboard ONBOARD_ARGS="--with-analytics" and open http://localhost:8088 with the operations demo account.

Access

  • Custom role DashboardViewer: can view dashboards, charts and datasets in the analytics schema only; no SQL Lab, no query editing, no database admin.
  • Keycloak role superset_dashboard_viewers (part of the Platform Admin composite) maps to DashboardViewer (superset/superset_config.py, superset/custom_roles.py).
  • In the app, Platform Admins open it via the external Dashboard menu item.

Dashboard 1 — Compute MatchMake System Metrics (marketplace)

Defined in superset/dashboards/marketplace_metrics.py.

  • Request analytics: total requests, requests per week, average time to contract (overall and by NCP), conversion rate (overall and by GPU), acceptance and rejection by NCP, custom-request percentage, contracted GPUs by month and platform.
  • User analytics: NCP and customer activity tiers with detail tables, new sign-ups in the last 4 weeks, logins per user over 90 days.
  • Capacity analytics: available, reserved and future GPUs, NCPs with capacity, capacity by platform and region, future pipeline by month.

Sources: views such as analytics.v_reservation_request_*, v_ncp_activity, v_customer_activity, v_user_actions, v_ncp_capacity_overview, v_future_pipeline_by_month.

Dashboard 2 — Feedback

Defined in superset/dashboards/feedback_metrics.py. KPIs: average rating, number of responses, satisfied versus dissatisfied, rating distribution, top reasons, journey summary, recent feedback. Filters: time, persona, journey. Source: analytics.v_feedback and a funnel view.
